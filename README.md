# Hospital-Management-SQL-Assignment
This is a SQL-based assignment project analyzing hospital management data. The project focuses on understanding patient flow, medical expenses, department performance, and doctor allocation using SQL queries.

### 📂 Dataset
**File:** `Hospital_Data.csv`
**Columns:**
- Hospital Name, Location, Department
- Doctors Count, Patients Count
- Admission Date, Discharge Date
- Medical Expenses

### 🛠 Tech Stack
- MySQL / PostgreSQL
- SQL Concepts: GROUP BY, JOINS, Aggregations, Date Functions

### 📝 Queries Covered
1. Total patients across all hospitals
2. Department with highest patient count
3. Average medical expenses per department
4. Hospital with maximum doctors
5. Average length of stay (Discharge - Admission)
6. Location-wise patient distribution
7. Monthly expense report
8. Top 3 expensive departments

### 📄 Files
- `Hospital_Data.csv` - Raw dataset
- `hospital_queries.sql` - All SQL queries
- `Hospital_Assignment_Answers.pdf` - PDF report
